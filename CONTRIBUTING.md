# Contributing

Report bugs through [GitHub Issues](https://github.com/MFarhan911/PadRevive/issues), including the Windows version, controller model, and steps to reproduce. Remove private device paths and personal information before sharing diagnostics.

Build with the .NET 10 SDK on Windows using `./Build.ps1`. Keep controller profiles data-only, preserve license notices, and verify changes with the included checks and a supported physical controller where applicable.

Pull requests are welcome for controller mappings, accessibility, interface improvements, and tested hardware support.
